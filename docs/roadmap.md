# Development roadmap

1. WPF/MVVM shell and live dashboard foundation (complete).
2. Read-only hardware/system inventory and editable language catalogs (complete).
3. Add read-only Windows diagnostics with captured command output and cancellation.
4. Add storage analysis with a file preview before any cleanup action.
5. Add read-only Windows management and security status views.
6. Add guarded BIOS/UEFI handoff, activity history, and exportable reports.

System-changing actions require explicit, contextual confirmation. No destructive
operation is scheduled or run automatically.
